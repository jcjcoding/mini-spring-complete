build.gradle	
「项目怎么构建」（依赖、编译版本）	
① 加依赖（如 implementation 'org.springframework.boot:spring-boot-starter-web'）；
② 确认 Java 21 版本配置（JavaLanguageVersion.of(21)）；
③ 会执行 ./gradlew bootRun 启动、./gradlew build 打包

application.yml（推荐）	
管「项目怎么运行」（端口、参数）	
① 改端口（server.port=8081）；
② 配置数据库 / Redis 等基础连接参数；
③ 不用拆分多环境，所有运行参数都写这里

自定义配置类（@Configuration）	
管「项目功能定制」（代码级配置）	
① 会写简单的配置类（如跨域、拦截器）；
② 知道「配置文件满足不了时，用配置类解决」（比如自定义线程池、多数据源）
